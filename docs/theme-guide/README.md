# 貓爪鍵盤主題設計手冊（圖片版）

給畫鍵盤主題的人：把一張完整的設計稿，拆成主題工作室裡可以一個一個做出來的東西（背景圖、按鍵底圖、圖案、顏色）。

照順序看 `guide-01.png` 到 `guide-14.png`：

| 頁 | 內容 |
| --- | --- |
| 1 | 封面、先記住三件事 |
| 2–3 | 鍵盤由下到上的 9 層 |
| 4–5 | 每一塊有多大 |
| 6–7 | 圖片要準備多大、注意事項 |
| 8–11 | 實際拆一張設計稿（1～11 號） |
| 12 | 目前做不到的地方 |
| 13 | 製作順序 |
| 14 | 交件清單、版型圖位置 |

**一次下載全部**：`catpaw-theme-design-kit.zip`（手冊 14 張＋[版型圖](../theme-templates/) 5 張）。在 GitHub 點開這個檔案後按右上角的下載按鈕。

手冊的網頁版、版型圖說明見 [theme-templates](../theme-templates/)。

尺寸以寬 1080px 的手機、按鍵高度預設值計算（App v0.30）。
