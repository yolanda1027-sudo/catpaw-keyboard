# 貓爪鍵盤主題設計手冊（圖片版）

給畫鍵盤主題的人：把一張完整的設計稿，拆成主題工作室裡可以一個一個做出來的東西（背景圖、按鍵底圖、圖案、顏色）。

照順序看 `guide-01.png` 到 `guide-18.png`：

| 頁 | 內容 |
| --- | --- |
| 1 | 封面、先記住三件事 |
| 2 | 主題怎麼存、每一頁怎麼設計 |
| 3–4 | 鍵盤由下到上的 9 層 |
| 5–7 | 每一塊有多大（含符號、顏文字、表情、剪貼簿、數字頁） |
| 8–9 | 其他 6 頁的版型圖（符號、顏文字、表情、我的貼圖、剪貼簿、數字） |
| 10–11 | 圖片要準備多大、注意事項 |
| 12–15 | 實際拆一張設計稿（1～11 號） |
| 16 | 目前做不到的地方 |
| 17 | 製作順序 |
| 18 | 交件清單、版型圖位置 |

**一次下載全部**：`catpaw-theme-design-kit.zip`（手冊 18 張＋[版型圖](../theme-templates/) 8 頁共 17 張）。在 GitHub 點開這個檔案後按右上角的下載按鈕。

手冊的網頁版、版型圖說明見 [theme-templates](../theme-templates/)。

尺寸以寬 1080px 的手機、按鍵高度預設值計算（App v0.52）。
